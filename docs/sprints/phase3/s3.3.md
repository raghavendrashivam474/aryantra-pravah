# Sprint S3.3 — Peer-to-Peer Logical Routing

## Objective
Enable destination-based logical peer communication: allowing higher layers to send messages directly to PeerId destinations without awareness of sockets, IP addresses, ports, or raw TCP connection IDs.

## Existing Baseline
- S3.2 complete (PeerId, PeerRecord, PeerRegistry operational, 113 tests passing).

## Implemented Capability
- **PeerRouter** (com.aryntra.pravah.peer.PeerRouter):
  - Bridges logical peer communication to transport dispatch.
  - Resolves destination PeerId -> PeerRecord -> active connectionId.
  - Pipeline: Message -> MessageEncoder.encode() -> FrameEncoder.encode() -> Transport.send(connectionId, framedBytes).
  - Predictable error handling: raises PeerRoutingException when destination is unregistered, disconnected, or on underlying transport failure.
- **PeerRoutingException** (com.aryntra.pravah.peer.PeerRoutingException):
  - Domain-specific exception extending PravahException.

## Files Added
- src/main/java/com/aryntra/pravah/peer/PeerRoutingException.java
- src/main/java/com/aryntra/pravah/peer/PeerRouter.java
- src/test/java/com/aryntra/pravah/peer/PeerRouterTest.java
- src/test/java/com/aryntra/pravah/peer/PeerRoutingIntegrationTest.java

## Files Modified
- None. Transport, TcpTransport, Message, FrameEncoder, and ProtocolSessionManager were completely protected and left untouched.

## API & Contract Changes
- Added PeerRouter providing send(PeerId destination, Message message) and send(PeerId sender, PeerId destination, String messageId, byte[] payload).

## Tests Added
- PeerRouterTest: 7 unit tests testing routing dispatch, encoding & framing verification, unknown peer failure, disconnected peer failure, transport failure handling, null validation, and multi-peer dispatch isolation.
- PeerRoutingIntegrationTest: 1 comprehensive end-to-end integration test with real TcpTransport nodes (Node A routing to Peer B and Peer C via logical PeerId over dynamic TCP sockets).

## Verification Summary
- **Total Tests:** 121 (87 Phase 2 baseline + 34 Phase 3 S3.1-S3.3 tests).
- **Failures / Errors:** 0.

## Architectural Decisions
- Transport contract kept 100% Peer-agnostic (Transport.send(String connectionId, byte[] payload) remains untouched).
- Destination is passed at dispatch time to the router rather than mutating the immutable Message record.
- Clean layer separation maintained: Peer Layer sits cleanly above Transport and Protocol Serialization.

## Out of Scope
- Adaptive routing, multi-path routing, latency scoring, offline message queues.
