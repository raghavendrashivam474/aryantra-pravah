# Sprint Report: S2.4 — Chat Semantics

## 1. Goal
Define and implement deterministic protocol-level state transitions and chat semantics for JOIN, MESSAGE, and LEAVE messages, cleanly separated from transport concerns.

## 2. Deliverables
1. **PeerState (com.aryntra.pravah.protocol.PeerState)**
   - Protocol lifecycle states: JOINED, LEFT.
   - Strictly transport-agnostic.

2. **ProtocolListener (com.aryntra.pravah.protocol.ProtocolListener)**
   - High-level domain event callbacks: onPeerJoined(), onMessageReceived(), onPeerLeft().

3. **ProtocolSessionManager (com.aryntra.pravah.protocol.ProtocolSessionManager)**
   - Deterministic state machine governing peer transitions.
   - Enforces valid ordering:
     - JOIN -> peer becomes JOINED. Duplicate JOIN rejected with ProtocolException.
     - MESSAGE -> delivered only if peer is JOINED. Message before JOIN or after LEAVE rejected with ProtocolException.
     - LEAVE -> peer becomes LEFT. Duplicate LEAVE or LEAVE without prior JOIN rejected with ProtocolException.
   - Supports re-joining after leaving.
   - Complete peer isolation (state of peer A does not affect peer B).

4. **Test Suite**
   - ProtocolSessionManagerTest (8 tests) covering all valid transitions, invalid transition rejections, re-joining, and multi-peer isolation.

## 3. Sprint Acceptance Gate
- [x] JOIN semantics defined and enforced.
- [x] MESSAGE semantics defined and enforced.
- [x] LEAVE semantics defined and enforced.
- [x] Logical peer identity (senderId) used for all session state.
- [x] State transitions deterministic and documented.
- [x] Multiple peer state isolated.
- [x] 70/70 tests passing, zero regressions.
