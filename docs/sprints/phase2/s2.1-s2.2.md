## 1. Objectives Delivered

### S2.1 — Message Model
- Created `com.aryntra.pravah.protocol.MessageType` (`JOIN=0x01`, `MESSAGE=0x02`, `LEAVE=0x03`).
- Created `com.aryntra.pravah.protocol.Message` as an immutable record containing:
  - `MessageType type`
  - `String senderId` (logical identity, distinct from socket address)
  - `String messageId` (unique logical message ID)
  - `byte[] payload` (with defensive copying on read and write)
- Full value-based equality and hash code semantics.

### S2.2 — Encoder / Parser
- Defined explicit, deterministic binary wire specification v1 (`MAGIC=0x50 0x52`, `VERSION=0x01`).
- Created `com.aryntra.pravah.protocol.MessageEncoder` producing Big-Endian byte arrays.
- Created `com.aryntra.pravah.protocol.MessageParser` with strict validation:
  - Header magic validation
  - Version validation
  - Unsigned short length parsing for identifiers
  - Payload length bounds validation
  - Trailing garbage byte detection
- Created `com.aryntra.pravah.protocol.ProtocolException` extending `PravahException`.
