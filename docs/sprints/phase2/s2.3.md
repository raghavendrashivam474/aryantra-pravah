# Sprint Report: S2.3 — Message Framing

## 1. Goal
Provide stream-safe message framing on top of continuous TCP streams without mutating or entangling MessageEncoder, MessageParser, or TcpTransport.

## 2. Deliverables
1. **FrameEncoder (com.aryntra.pravah.protocol.FrameEncoder)**
   - Prepends 4-byte big-endian length prefix.
   - Enforces 16 MB maximum frame boundary (MAX_FRAME_SIZE).
   - Rejects zero-length and oversized payloads.

2. **FrameDecoder (com.aryntra.pravah.protocol.FrameDecoder)**
   - Stateful per-connection byte stream accumulator.
   - Safely extracts complete encoded messages across fragmented, coalesced, and mixed TCP reads.
   - Rejects invalid or malicious length indicators with ProtocolException.

3. **ADR-003 (docs/architecture/ADR-003-length-prefixed-framing.md)**
   - Documents framing architecture, envelope layout, and per-connection isolation rules.

4. **Test Suite**
   - Unit tests: FrameEncoderTest (5 tests), FrameDecoderTest (11 tests).
   - TCP Integration tests: FramingTcpIntegrationTest (4 tests) covering fragmentation, coalescing, and concurrent multi-peer isolation over real sockets.

## 3. Sprint Acceptance Gate
- [x] Explicit framing strategy chosen and documented (4-byte length prefix).
- [x] FrameEncoder implemented.
- [x] Per-connection FrameDecoder implemented.
- [x] Partial reads, coalesced reads, and oversized frames verified.
- [x] Real TCP integration tested.
- [x] 62/62 tests passing, zero regressions.
