# S7.1 — Android Runtime Foundation

## Baseline
- Baseline: v0.6.6 (HEAD: 4f41f1d)
- Core Tests: 319 / 319 passing

## Objective
Establish an Android runtime foundation to host Aryntra Pravah core without modifying core domain models or lifecycle guarantees.

## Implementation Details
1. **Module Structure**: Created `android/` directory with a standard Gradle Android application layout (`:app`).
2. **Core Integration**: The Android module depends directly on `pravah-core.jar` built from Maven core sources.
3. **PravahAndroidRuntime**: Provides lifecycle adaptation mapping Android-friendly start/stop operations to the core `PravahRuntime`.
4. **Lifecycle State Integrity**: Enforces clean re-instantiation when starting from `STOPPED` or `FAILED` states to prevent stale state corruption.
