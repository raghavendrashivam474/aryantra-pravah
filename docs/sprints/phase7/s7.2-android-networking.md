# S7.2 — Android Networking

## Baseline
- Baseline: S7.1 complete
- Core Tests: 319 / 319 passing

## Objective
Enable Android networking using Pravah's existing `Transport` contract (`TcpTransport`), establishing real TCP connections and mapping them directly to `PeerConnectivityRegistry` without leaking low-level sockets to application code.

## Key Decisions & Architecture
1. **Transport Contract Revalidation**: Revalidated `Transport`, `TransportListener`, and `TcpTransport` boundaries (Section 14).
2. **PravahAndroidNetworkManager**: Implemented Kotlin network coordinator managing transport start/stop, connection opened/closed events, and direct promotion/deactivation of `ConnectivityPath` entries.
3. **No Application Leakage**: All `java.net.Socket` and `ServerSocket` interactions remain strictly behind the `Transport` interface. Application logic continues to interact with `PeerId` and `ConnectivityPath`.
4. **Connectivity Integration**:
   - Discovered endpoints map to `PathState.CANDIDATE`.
   - Successful TCP connections promote paths to `PathState.ACTIVE`.
   - Disconnections or socket drops automatically deactivate paths to `PathState.INACTIVE`.
