## Problem Encountered & Fix

**Issue:** `LanPeerDiscovery` constructor validates `localTcpPort` must be 1–65535. The original manager instantiated it eagerly with `port = 0` (dynamic binding), which crashed all 9 S7.4 messaging tests with `IllegalArgumentException`.

**Fix:** Made `LanPeerDiscovery` lazy — it is only constructed inside `startDiscovery()` after `transport.start()` has resolved the actual bound port. This restored all 23 Android tests to green with no behavioral change to the messaging path.

## What the APK Does on a Phone

```
[ START ]       → Boots TcpTransport + PresenceManager
[ DISCOVER ]    → Starts UDP broadcast, lists discovered peers
[ CONNECT ]     → TCP handshake + JOIN to first discovered peer
[ SEND ]        → Sends typed text, shows ACK/DELIVERED in log
[ STOP ]        → Tears down everything cleanly
```

Event log shows timestamped: runtime start, discovery, peer found, TCP connect, JOIN, message sent/received, ACK, delivery confirmation.
